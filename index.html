Hướng dẫn kết nối Google Sheets
1

Tạo Google Sheet

Mở sheets.google.com, tạo Sheet mới. Tạo 3 tab: Products, History, Config.

Tab Products — cột: id | name | color | size | qty | color_hex | low_threshold
Tab History — cột: timestamp | type | product_id | name | meta | qty | note

2

Lấy Sheet ID

Nhìn vào URL của Sheet:
docs.google.com/spreadsheets/d/[SHEET_ID]/edit

Copy phần [SHEET_ID] dán vào Cài đặt.

3

Tạo Google API Key

Vào console.cloud.google.com → tạo project mới → bật Google Sheets API → vào Credentials → Create → API Key. Dán key vào Cài đặt.

4

Chia sẻ Sheet

Nhấn Share trên Sheet → đổi thành "Anyone with the link can view". Để ghi dữ liệu (nhập/xuất kho) cần dùng Google Apps Script — xem bước 5.

5

Cài Apps Script để ghi dữ liệu

Trong Sheet → Extensions → Apps Script → paste đoạn script được tạo sẵn (liên hệ để nhận script). Deploy as Web App, copy URL dán vào Cài đặt.

💡 Mẹo: Trong lúc chờ setup xong, bật chế độ demo trong Cài đặt để test toàn bộ luồng nhập/xuất với dữ liệu mẫu.
